## 🚀 Featured QA Projects

A **Playwright + TypeScript E2E automation project** built around a real Angular application.

Highlights:

- Page Object Model
- Reusable fixtures and test utilities
- Stable, accessibility-oriented locators
- Cross-browser testing
- Smoke and regression coverage
- Accessibility checks
- CI execution with GitHub Actions
- Test diagnostics and failure investigation
- Focus on maintainability and test isolation

An Angular application used as the system under test for my E2E automation project.

It includes complex reactive forms, validation rules, dynamic states, and user interaction flows that provide realistic scenarios for automated testing.
