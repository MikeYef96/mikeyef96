# Hi, I'm Mykhailo 👋

## QA Automation Engineer & SDET · Playwright · TypeScript · Python

Frontend & Full-Stack Engineer with **5+ years of experience** transitioning into **QA Automation and SDET roles**. Because I know how enterprise applications are built from the ground up, I know precisely where they break. I specialize in building robust test automation frameworks, API validation, CI/CD quality gates, and eliminating production bugs before they reach users.

---

## 🚀 What I Bring to QA

- 🛠️ **Test Automation:** Building scalable E2E frameworks from scratch using **Playwright, TypeScript, Cypress, and Jest**.
- 🔌 **API & Integration Testing:** Validating REST and GraphQL endpoints, authentication flows, RBAC, and WebSockets using **Postman, Playwright, and Python scripts**.
- ⚙️️ **CI/CD Quality Gates:** Integrating automated test suites into **GitHub Actions** pipelines to enforce strict regression and deployment standards.
- 🐞 **Production Triage & Monitoring:** Experienced in analyzing production issues using **Sentry**, error tracking, and performance metrics.
- 🏗️ **Developer Empathy:** Leveraging 5+ years of enterprise frontend/backend experience (Angular, React, Node.js) to write clean, maintainable test code and collaborate seamlessly with development teams.
